## О проекте

Расширение для Хрома, представляющее собой хранилище ссылок.

Проект открыт, но реальные данные, с которыми работаю лично я, закинул в гитигнор.
В папке проекта лежит заглужка в виде файла links-data-example

---

## Возможности

При клипке на кнопку соответствующая ссылка мгновенно копируется в буфер обмена.
Все ссылки разбиты по категориям.
Ваши ссылки хранятся локально (файл links-data.js), файл занесен в гитигнор

## Установка

### Способ 1

1. **Скачайте проект:**

```bash
git clone https://github.com/didu4/my-links-storage.git
cd my-links-storage
```

2. **Настройте свои ссылки:**

```bash
cp links-data.example.js links-data.js
```

3. **Измените содержимое файла, вставив свои данные для работы**

4. **Загрузите расширение в Chrome:**

- Перейдите на `chrome://extensions/`
- Включите **"Режим разработчика"**
- Нажмите **"Загрузить распакованное расширение"**
- Выберите папку `my-links-storage`

5. Кликните на иконку расширения в панели инструментов и пользуйтесь.

---

### Способ 2

1. Скачайте ZIP-архив с [GitHub Releases](https://github.com/didu4/my-links-storage/releases)
2. Распакуйте в любую папку
3. Создайте и настройте файл `links-data.js` (см. способ 1)
4. Загрузите расширение в Chrome (см. способ 1)
